# 04 — API Specification

Base URL: `/api/v1`. OpenAPI auto-generated by FastAPI at `/docs` / `/openapi.json`.
All endpoints are versioned; breaking changes introduce `/api/v2` while `/api/v1` is maintained.

## 4.1 Conventions

- **Auth**: `Authorization: Bearer <JWT>` or `X-API-Key: <key>` (machine-to-machine).
- **Pagination**: `?limit=` (default 50, max 200) + `?offset=`; responses: `{items, total, limit, offset}`.
- **Filtering**: `?filter[field]=value`, `?filter[status]=embedded`, `?q=` full-text.
- **Errors**: RFC 7807 problem+json `{type, title, status, detail, trace_id, errors[]}`.
- **Idempotency**: `Idempotency-Key` header honored on POST source/webhook.
- **Streaming**: SSE (`text/event-stream`) for chat; events carry `event:` + `data:`.

## 4.2 Endpoints

### Auth
| Method | Path | Description |
|--------|------|-------------|
| POST | `/auth/login` | Exchange credentials → `{access_token, refresh_token}` |
| POST | `/auth/refresh` | Rotate access token |
| POST | `/auth/logout` | Revoke refresh token |
| GET | `/auth/me` | Current user + permissions |

### Chat
| Method | Path | Description |
|--------|------|-------------|
| POST | `/chat/sessions` | Create conversation |
| GET | `/chat/sessions?workspace=` | List (paginated, filterable, pinned first) |
| GET | `/chat/sessions/{id}` | Load conversation + history |
| PATCH | `/chat/sessions/{id}` | Rename, pin/unpin, share |
| DELETE | `/chat/sessions/{id}` | Delete (soft) |
| POST | `/chat/stream` | **SSE**: ask a question (streams answer tokens) |
| POST | `/chat/answer` | Non-streaming answer (returns full structured response) |
| GET | `/chat/sessions/{id}/feedback` | Feedback for messages |
| POST | `/chat/feedback` | Submit feedback `{message_id, rating, comment}` |

`POST /chat/stream` request:
```json
{
  "session_id": "…",           // optional; omitted → new session
  "question": "Does Tryvium support WhatsApp?",
  "workspace_id": "…",
  "options": {"mode": "hybrid", "rerank": true, "max_context_chars": 8000}
}
```
SSE events: `session.created`, `started`, `delta` (text), `citations`, `grounded`, `confidence`,
`usage` (tokens/model), `done`, `error`.

`POST /chat/answer` response:
```json
{
  "answer": "…",
  "grounded": true,
  "confidence": 0.87,
  "citations": [{"chunk_id":"…","url":"https://www.tryvium.ai/…","heading":"…","snippet":"…"}],
  "model": {"provider":"openai","model":"gpt-4o-mini"},
  "usage": {"prompt_tokens":512,"completion_tokens":143,"total_tokens":655},
  "message_id": "…",
  "session_id": "…",
  "retrieval": {"top_k":24,"reranked_top_k":8,"query_rewrites":["…"],"latency_ms":421}
}
```

## 4.3 Schemas (representative)

`KnowledgeSourceCreate`: `{type: enum, config: object, schedule: {mode: manual|cron, cron: str|None}, display_name, workspace_id}`

`Chunk` (read model): `{id, doc_id, doc_version, section_path, heading, text, char_offset, lang, sha256, url, source_id, workspace_id, published_at, updated_at}`

`Message`: `{id, session_id, role, content, citations, confidence, grounded, model, provider, tokens, created_at}`

## 4.4 Rate limits
- Global: 60 req/min per user (429 with `Retry-After`).
- Chat: 20 req/min; streaming messages consumed at higher token ceiling per plan.

## 4.5 Webhook signature
`X-AgentAI-Signature: sha256=HMAC(webhook_secret, timestamp + "." + raw_body)`; `X-AgentAI-Timestamp`
must be within 5 minutes. Replay protection via Redis nonce.
